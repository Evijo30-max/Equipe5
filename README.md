### Organisation des dossiers
Chaque projet possède :
- `scripts/` → code source
- `captures/` → captures d’écran
- `rapport/` → textes et rapport final
- `presentation/` → support de soutenance
- `donnees/` → fichiers de données (Projets 2 et 3)
- `graphiques/` → graphiques R (Projet 3 uniquement)

### Règles de l’équipe
- Nommage strict : `P<n°>_<numéro>_<sujet>_<NOM>`
- Aucun fichier généré par IA n’est accepté sans relecture et compréhension
- Chaque membre doit pouvoir expliquer **tout** le projet à la soutenance
- Relecture croisée obligatoire avant assemblage
